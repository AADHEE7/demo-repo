How a week works

Teach, write, then test.

Counselling before a seat

A parent comes with the latest answer paper. We say honestly if a batch here is the right size and speed. One trial class follows, in a real batch.

Concept, then problems

Each subject meets twice a week. The second meeting is a problem set. Phones stay in the lobby pouch. Doubts stay after the bell for half an hour.

Saturday paper

Marked by Monday. If a score drops two tests in a row, the class teacher calls home that week, not after the public exam.
